# realme Neo7 RMX5060 — KernelSU Next + SUSFS source package

Corresponding source metadata and local patches for the tested unofficial
KernelSU Next + SUSFS kernel release for `RMX5060_16.0.9.400(CN01)`.

This repository contains source references, immutable commits, the final
config, patch series, source diff, license notices, and a public build recipe.
It does not contain stock OEM images, device backups, private logs, ADB keys,
or personal data.

See [SOURCES.md](SOURCES.md), [patches/SERIES](patches/SERIES), and
[docs/REDISTRIBUTION_AUDIT.md](docs/REDISTRIBUTION_AUDIT.md).

Release status: **TESTED**, not stable or official.
